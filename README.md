# odin-inventory-app

Is a web application for organizing a manga collection. It lets users add, view, update and remove manga records, including descriptions, publication status and start and end dates. Manga can be associated with staff members and their roles and grouped by genre.

The app also provides management pages for staff, roles and genres, with searchable selection controls to make it easier to assign credits and categories while editing a manga. It is built with Node.js, Express, EJS, and PostgreSQL.
